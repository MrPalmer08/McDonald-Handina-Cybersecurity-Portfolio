4. Kerberoasting & DCSync Detection Engineering

Diagram simulation · Identity attack telemetry & detection | illustrative workflow

Controlled identity-attack simulation → AD audit events (4769 / 4662) → Splunk correlation and ATT&CK-aligned detection.

Project D - Detection Identity Attacks

Kerberoasting & DCSync Detection Engineering

Executed Active Directory identity attacks with Impacket (GetUserSPNs.py and secretsdump.py), configured GPO audit policies, and built custom Splunk SPL detections targeting MITRE ATT&CK T1558.003 and T1003.006.

  • Event ID 4769: Service ticket requests with weak RC4 encryption (0x17)
  • Event ID 4662: Directory service replication from non-DC hosts
  • False-positive tuning: allowlist approved legacy RC4 (0x17) service accounts only by account, SPN and expected source; review exceptions regularly and alert on deviations.
